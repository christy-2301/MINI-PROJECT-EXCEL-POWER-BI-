Retail Store Sales Analysis & Power BI Dashboard

 📊 Project Overview
This project analyzes retail store sales data using Microsoft Excel and Power BI. The dataset was cleaned and prepared in Excel, followed by Pivot Table analysis and the development of an interactive Power BI dashboard.

🛠️ Tools Used
- Microsoft Excel
- Power BI

🔄 Project Process
- Cleaned and prepared 999 retail transaction records
- Handled missing and inconsistent values
- Calculated and analyzed **Total Spent**
- Created Pivot Tables for sales analysis
- Created DAX measures in Power BI
- Developed an interactive dashboard

📈 Dashboard
The dashboard provides insights into:
- Total Sales
- Number of Transactions
- Average Transaction Value
- Sales by Category
- Sales by Payment Method
- Sales by Location
- Yearly Sales Performance
